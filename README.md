# مرصد رسكورا — إصلاحات الطلبات

هذه النسخة تتضمن إصلاحين محددين فقط:
1. عند رفض عرض السعر، يحفظ النظام الحالة `rejected_by_client` ثم ينقل المستخدم إلى «طلباتي». يظهر الرفض باللون الأحمر، ولا يظهر زر «عرض التفاصيل» للعرض المرفوض.
2. عند فتح نموذج «أصولي/طلب جديد»، يبدأ النموذج فارغًا ولا يعيد بيانات الأصل السابقة. تبقى الطلبات القديمة محفوظة في السجل ولا يتم حذفها.

ملاحظة: هذا نموذج واجهة تجريبي يعتمد على localStorage في المتصفح، ولا يرسل إشعارات أو يشارك البيانات بين الأجهزة حتى ربطه بقاعدة البيانات لاحقًا.
