# Marsad Riskora | مرصد رسكورا

واجهة نموذج أولي للتأمين البارامتري باللغة العربية، محسّنة لتوضيح رحلة العميل.

## الصفحات
- الرئيسية مع ملخص رحلة العميل بأربع خطوات.
- أصولي / إضافة أصل.
- طلب التغطية ومراجعة الطلب.
- اختيار الباقة بعد محاكاة قبول الأصل.
- مراجعة عرض التغطية والدفع التجريبي.
- الوثيقة التجريبية، المؤشرات، طلبات التعويض، وطلباتي ووثائقي.
- بيانات النموذج مع فلترة السنوات وتحميل ملف Excel.
- الإعدادات: حجم النص وتقليل الحركة ومعلومات عن النموذج.

## النشر على GitHub Pages
ارفعي محتويات هذا المجلد إلى جذر المستودع، مع بقاء `index.html` و`style.css` و`app.js` ومجلد `data` في أماكنها.

## ملاحظات مهمة
بيانات الطقس والأضرار محاكاة تعليمية وليست سجلات رسمية. الأسعار والدفع والقبول والوثائق محاكاة فقط. حقول البطاقة في الصفحة للعرض ولا تتصل ببوابة دفع. لا توجد قاعدة بيانات أو مصدر طقس مباشر.
