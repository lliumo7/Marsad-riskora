# مرصد رسكورا — النسخة المطوّرة V3

واجهة عربية RTL متجاوبة لنموذج أولي للتأمين البارامتري.

## الملفات
- `index.html`: صفحات التطبيق.
- `style.css`: التنسيق والتجاوب.
- `app.js`: التنقل، اختيار الباقات، الطلبات والمؤشرات التوضيحية.

## الإضافات في V3
- إضافة صفحة مستقلة لمؤشرات المخاطر، مع المنطقة ونوع المؤشر وحد التفعيل والحالة ومصدر البيانات.
- إضافة أنواع مخاطر إضافية.
- تقسيم المرفقات إلى صور قبل الخطر، وصور بعد الخطر، ومستندات العميل وربط أسمائها بملخص الطلب.
- إظهار الباقة المختارة بوضوح مع زر يتغير إلى «تم اختيار هذه الباقة».
- إضافة صفحات للشروط والخصوصية وأزرار رجوع داخل الصفحات الفرعية.
- توضيح أن المؤشرات والأسعار والمنافع بيانات محاكاة وليست بيانات رسمية أو عرض تأمين فعليًا.

## طريقة النشر على GitHub Pages
ارفعي الملفات الثلاثة (`index.html`, `style.css`, `app.js`) إلى جذر المستودع واستبدلي النسخة القديمة، ثم اختاري Commit changes. ارفعي `README.md` اختياريًا للتوثيق.

## حدود مهمة
- هذه واجهة تجريبية فقط: لا يوجد تسجيل دخول آمن أو خادم أو دفع حقيقي.
- الملفات لا تُرفع إلى خادم، وتظهر أسماؤها في جلسة المتصفح فقط.
- المؤشرات محاكاة داخلية وليست بيانات طقس مباشرة. لا تستخدمي بيانات شخصية حساسة في النسخة المنشورة.
- لا تُعد بطاقة الطلب وثيقة تأمين صادرة، ولا تمثل مبالغ التعويض حسابًا اكتواريًا معتمدًا.
