# مرصد رسكورا — معاينة V5

نسخة واجهة تجريبية مستوحاة من لوحة الصفحات المرجعية الزرقاء والبيضاء. تحتوي على 10 صفحات مترابطة وتدفق العميل: إضافة الأصل ← تحديد الخطر وإرسال الطلب ← مراجعة وقبول تجريبي ← اختيار الباقة ← مراجعة العرض والدفع التجريبي ← وثيقة توضيحية ← متابعة المؤشر ← طلب تعويض ← طلباتي ووثائقي.

## التشغيل
- افتح `index.html` في المتصفح، أو ارفع الملفات الثلاثة `index.html`, `style.css`, `app.js` إلى جذر مستودع GitHub Pages.
- `design-reference.png` هي صورة مرجعية فقط وليست جزءًا مطلوبًا من تشغيل الواجهة.

## تنبيه
هذا نموذج واجهة فقط. لا توجد قاعدة بيانات أو تسجيل دخول حقيقي أو معاينة موظف فعلية أو بوابة دفع أو بيانات طقس مباشرة. الأسعار والمؤشرات والوثائق تجريبية، ولا تمثل عرضًا أو وثيقة تأمين حقيقية. زر «محاكاة قبول الأصل» موجود فقط لتجربة انتقال الصفحات.
