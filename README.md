# Marsad Riskora | مرصد رسكورا

واجهة نموذج أولي للتأمين البارامتري، تتضمن رحلة العميل وصفحة بيانات النموذج.

## التشغيل والنشر
- ارفعي محتويات هذا المجلد إلى جذر مستودع GitHub Pages.
- تأكدي أن `index.html` في الجذر، وأن `style.css` و`app.js` ومجلد `data` مرفوعة معه.
- صفحة «بيانات النموذج» تعرض بيانات تجريبية من 2017 إلى 2025 ويمكن تحميل ملف Excel منها.

## ملاحظة مهمة
بيانات الأمطار والرياح والحرارة والأضرار المعروضة محاكاة تعليمية لاختبار الواجهة والحسابات، وليست سجلات أرصاد رسمية أو بيانات موثقة لمنطقة محددة. الأسعار والدفع والقبول والوثائق محاكاة أيضًا. لا توجد قاعدة بيانات أو بوابة دفع أو مصدر طقس مباشر.
