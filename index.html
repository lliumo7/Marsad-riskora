سياسة الاستخدام

معلومات مهمة قبل تجربة المنصة

طبيعة الخدمة

مرصد رسكورا نموذج أولي لأغراض العرض والتجربة التعليمية، وليس خدمة تأمين تجارية أو عرضًا ملزمًا.

البيانات والنتائج

بيانات الطقس والأضرار المعروضة تجريبية، وقد لا تمثل ظروف أي منطقة فعلية. النتائج الحسابية للتوضيح فقط ولا ينبغي الاعتماد عليها لاتخاذ قرار مالي أو تأميني حقيقي.

الدفع والوثائق

لا يتم تحصيل مبالغ مالية، ولا تصدر وثائق تأمين فعلية. أي مبالغ أو حالة دفع أو وثيقة تظهر في النموذج هي محاكاة.

الملفات والخصوصية

النسخة الحالية لا تتصل بخادم أو قاعدة بيانات. تجنّب إدخال معلومات حساسة أو بيانات دفع حقيقية. الملفات التي تختارها تبقى ضمن تجربة الواجهة ولا تُرسل إلى جهة تأمين.

مكافحة الاحتيال

أي مراجعة أو قبول أو تحقق ظاهر في الواجهة هو توضيحي فقط ولا يمثل إجراءً تنظيميًا أو اعتمادًا فعليًا.
