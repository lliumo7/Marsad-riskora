# مرصد رسكورا — النسخة التجريبية الثانية
ملفات الواجهة: `index.html` و`style.css` و`app.js`.

## ما تم تحسينه
- شاشة دخول موحدة تجريبية مع نوع الحساب (فرد أو منشأة/أعمال).
- تنظيم الأيقونات والتنقل السفلي: الرئيسية، طلب تغطية، تغطياتي، الإعدادات.
- أنواع حماية متعددة ومناطق المملكة الثلاث عشرة.
- ثلاث باقات: أساسية، متوازنة، أعمال.
- نموذج بيانات العميل وموقع الأصل وإرفاق الملفات ضمن طلب التغطية.
- بطاقة ملخص طلب مفصلة بدل عرض وثيقة فارغة.
- إعدادات منظمة للملف الشخصي والمظهر والإشعارات.
- قيم مؤشرات ومبالغ توضيحية فقط؛ ليست بيانات طقس مباشرة أو عرض تأمين حقيقي.

## مهم
هذه واجهة أمامية تجريبية فقط. تسجيل الدخول غير موثّق ولا توجد قاعدة بيانات أو رفع ملفات لخادم أو دفع حقيقي. البيانات والطلبات تبقى في ذاكرة الصفحة وتختفي عند إعادة التحميل. يلزم تطوير خلفية آمنة قبل استخدام بيانات العملاء الحقيقية.
