# مرصد رسكورا — إعادة تصميم الواجهة
ارفعي الملفات الثلاثة `index.html` و`style.css` و`app.js` إلى جذر مستودع GitHub Pages.
- تنقل سفلي: الرئيسية، طلب تغطية، تغطياتي، الإعدادات.
- القائمة العلوية للعناصر الثانوية: الوثائق والشروط، المرفقات، الإشعارات، الدعم، عن المنصة.
- إرفاق صور وملفات PDF للعرض المحلي، مع ثلاثة أمثلة توضيحية.
- إعدادات المظهر الفاتح/الداكن.
- هذه مرحلة تصميم وتنقل فقط. لا توجد بيانات طقس حقيقية أو تجريبية مرتبطة بعد، كما طلبتِ أن نبدأ بها بعد الانتهاء من الشكل. لا يوجد تسجيل دخول فعلي أو رفع ملفات إلى خادم أو دفع أو تعويض حقيقي.
